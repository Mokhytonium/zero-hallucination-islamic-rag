# واژه‌نامه

تعریف اصطلاحات فنی و متون به‌کاررفته در این پروژه.

## اصطلاحات فنی

| اصطلاح | توضیح |
|--------|-------|
| **RAG** | Retrieval-Augmented Generation؛ معماری‌ای که ابتدا اطلاعات مرتبط را بازیابی می‌کند و سپس (معمولاً) مدل زبانی بر اساس آن پاسخ می‌سازد. در این پروژه، بخش «تولید» به حداقل رسیده و متن مستقیماً از دیتابیس خوانده می‌شود. |
| **Embedding (بردارسازی)** | تبدیل متن به یک بردار عددی چندبعدی که معنای متن را بازنمایی می‌کند. |
| **Dense Vector** | بردار متراکم و با ابعاد بالا که برای جست‌وجوی معنایی استفاده می‌شود. |
| **Sparse Index** | ایندکس واژگانی (معکوس) برای تطابق دقیق کلمات؛ مکمل جست‌وجوی برداری. |
| **Hybrid Retrieval** | ترکیب جست‌وجوی برداری (Dense) و واژگانی (Sparse) برای دقت بالاتر. |
| **Cosine Similarity** | معیار شباهت میان دو بردار بر اساس زاویه‌ی آن‌ها؛ بازه‌ی آن معمولاً بین -۱ و ۱ است. |
| **Top-k** | انتخاب k نتیجه‌ی برتر بر اساس امتیاز شباهت. |
| **Threshold (آستانه)** | حد نصاب امتیاز؛ نتایج پایین‌تر از آن حذف می‌شوند. |
| **MMR** | Maximal Marginal Relevance؛ الگوریتمی برای انتخاب نتایج هم‌زمان مرتبط و متنوع (کاهش تکرار). پارامتر `λ` تعادل بین مرتبط‌بودن و تنوع است. |
| **LLM Judge (داور)** | مدل زبانی‌ای که فقط تصمیم می‌گیرد یک سند مرتبط است یا نه؛ متن تولید نمی‌کند. |
| **T = 0 (دما)** | تنظیم دما روی صفر برای کاهش واریانس و افزایش پایداری خروجی. |
| **NLI** | Natural Language Inference؛ تشخیص رابطه‌ی منطقی (استلزام/تناقض/بی‌طرفی) بین دو متن. |
| **Hallucination (توهم)** | تولید اطلاعات نادرست یا ساختگی توسط مدل زبانی. |
| **Hydration (واکشی مستقیم)** | خواندن متن و آدرس نهایی مستقیماً از دیتابیس بر اساس شناسه‌های تأییدشده. |
| **Contextual Chunking** | قطعه‌بندی همراه با تزریق بافت (متن مجاور و اطلاعات تاریخی) برای حفظ سیاق. |

## اصطلاحات متون دینی

| اصطلاح | توضیح |
|--------|-------|
| **قرآن کریم** | متن وحیانی اسلام؛ مرجع اصلی. |
| **آیه** | کوچک‌ترین واحد مستقل متن قرآن. |
| **سوره** | فصلی از قرآن شامل مجموعه‌ای از آیات. |
| **شأن نزول** | بافت تاریخی و مناسبت نزول یک آیه؛ کلید تشخیص تعمیم‌پذیری آیه. |
| **نهج‌البلاغه** | مجموعه‌ای از خطبه‌ها، نامه‌ها و حکمت‌های منسوب به امام علی (ع). |
| **خطبه / نامه / حکمت** | سه گونه‌ی متن در نهج‌البلاغه. |
| **الکافی** | یکی از مهم‌ترین مجموعه‌های حدیثی شیعه، شامل اصول، فروع و روضه. |
| **حدیث** | روایت منقول از معصوم. |
| **سند / سلسله‌ی راویان (اسناد)** | زنجیره‌ی راویانی که حدیث را نقل کرده‌اند. |
| **متن (متن حدیث)** | محتوای اصلی کلام معصوم، بدون سلسله‌ی راویان. |
| **معصوم** | در اصطلاح شیعه، شخصیت‌های پاک‌دامن که کلامشان حجت است (پیامبر و ائمه). |
| **اعتبار سندی** | ارزیابی متنی از نظر درستی زنجیره‌ی سند؛ در این پروژه به‌صورت یک **امتیاز الگوریتمی** برای رتبه‌بندی استفاده می‌شود، نه حکم قطعی. |
| **رجال** | دانش بررسی احوال راویان حدیث. |
| **اصول / فروع / روضه** | سه بخش اصلی الکافی. |
| **باب** | فصل یا زیربخش موضوعی در یک کتاب حدیثی. |
