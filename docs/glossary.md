# واژه‌نامه

تعریف اصطلاحات فنی و متون به‌کاررفته در این پروژه.

## اصطلاحات فنی

| اصطلاح | توضیح |
|--------|-------|
| **RAG** | Retrieval-Augmented Generation؛ معماری‌ای که ابتدا اطلاعات مرتبط را بازیابی می‌کند و سپس (معمولاً) مدل زبانی بر اساس آن پاسخ می‌سازد. در این پروژه، بخش «تولید» به حداقل رسیده و متن مستقیماً از دیتابیس خوانده می‌شود. |
| **Embedding (بردارسازی)** | تبدیل متن به یک بردار عددی چندبعدی که معنای متن را بازنمایی می‌کند. |
| **Dense Vector** | بردار متراکم و با ابعاد بالا که برای جست‌وجوی معنایی استفاده می‌شود. |
| **Sparse Index** | ایندکس واژگانی (معکوس) برای تطابق دقیق کلمات؛ مکمل جست‌وجوی برداری. |
| **BM25 / FTS5** | BM25 تابع رتبه‌بندی واژگانی کلاسیک؛ FTS5 پیاده‌سازی داخلی SQLite از آن. در این پروژه جست‌وجوی واژگانی بدون هیچ توکنی انجام می‌شود. |
| **Hybrid Retrieval** | ترکیب جست‌وجوی برداری (Dense) و واژگانی (Sparse) برای دقت بالاتر. |
| **RRF** | Reciprocal Rank Fusion؛ ادغام چند فهرست رتبه‌بندی‌شده با امتیاز `وزن / (k + رتبه)`. در این پروژه وزن‌ها زبان‌آگاه‌اند (فارسی/عربی). |
| **Cosine Similarity** | معیار شباهت میان دو بردار بر اساس زاویه‌ی آن‌ها؛ بازه‌ی آن معمولاً بین -۱ و ۱ است. |
| **Top-k** | انتخاب k نتیجه‌ی برتر بر اساس امتیاز شباهت. |
| **Cross-Encoder (بازرتبه‌بند)** | مدلی که جفتِ «پرسش–سند» را با هم می‌خواند و امتیاز ارتباط می‌دهد؛ برخلاف Embedding که دو متن را جداگانه encode می‌کند. دقیق‌تر ولی کندتر؛ در این پروژه `BGE-reranker-v2-m3` محلی روی CPU برای جبران خطای رتبه‌بندیِ بازیابی اولیه استفاده می‌شود. |
| **Threshold (آستانه)** | حد نصاب امتیاز؛ نتایج پایین‌تر از آن حذف می‌شوند. در این پروژه به‌جای آستانه‌ی ثابت، **کف نسبی** (کسری از بهترین امتیاز RRF) استفاده می‌شود. |
| **MMR** | Maximal Marginal Relevance؛ الگوریتمی برای انتخاب نتایج هم‌زمان مرتبط و متنوع (کاهش تکرار). پارامتر `λ` تعادل بین مرتبط‌بودن و تنوع است. در طرح پالایش منابع آتی؛ فعلاً پیاده‌سازی نشده. |
| **LLM Judge (داور)** | مدل زبانی‌ای که فقط تصمیم می‌گیرد یک سند مرتبط است یا نه؛ متن تولید نمی‌کند. |
| **T = 0 (دما)** | تنظیم دما روی صفر برای کاهش واریانس و افزایش پایداری خروجی. |
| **NLI** | Natural Language Inference؛ تشخیص رابطه‌ی منطقی (استلزام/تناقض/بی‌طرفی) بین دو متن. |
| **Hallucination (توهم)** | تولید اطلاعات نادرست یا ساختگی توسط مدل زبانی. |
| **Hydration (واکشی مستقیم)** | خواندن متن و آدرس نهایی مستقیماً از دیتابیس بر اساس شناسه‌های تأییدشده. |
| **واژه‌یابی (Concordance)** | شمارش و نمونه‌برداری از کاربردهای صورت دقیق یک واژه در قرآن با FTS5؛ صریحاً **نه ریشه‌ی صرفی** — جدول ریشه در دیتابیس وجود ندارد و هیچ تحلیل صرفی تولید نمی‌شود. |
| **Contextual Chunking** | قطعه‌بندی همراه با تزریق بافت (متن مجاور و اطلاعات تاریخی) برای حفظ سیاق. |

## اصطلاحات داوری و ارزیابی

| اصطلاح | توضیح |
|--------|-------|
| **`Direct_Match` (تطبیق مستقیم)** | آیه هم‌جهت و منطبق با گزاره است؛ در بخش «تطبیق اصلی» نمایش داده می‌شود. |
| **`Conditional_Match` (تطبیق مشروط)** | آیه هسته‌ی گزاره را می‌پذیرد ولی قید سازگار اضافه می‌کند؛ در «شواهد پشتیبان». اگر گزاره ادعای عام باشد و آیه آن را محدود کند، هسته دوام نمی‌آورد و برچسب درست `Context_Mismatch` است. |
| **`Contradiction` (تضاد دیدگاه)** | آیه همان موضوع را نقد/رد می‌کند؛ به‌عنوان «دیدگاه منتقد» نگه داشته می‌شود. |
| **`Context_Mismatch` (خطای شأن نزول/محدودیت)** | آیه به موقعیت/شرط/گروه خاصی محدود است و به ادعای عام تعمیم‌پذیر نیست؛ از خروجی حذف می‌شود. محدودیت **متنی** کافی است؛ واقعه‌ی گزارش‌شده لازم نیست. |
| **`Superficial_Match` (تشابه سطحی)** | اشتراک صرفاً لفظی بدون رابطه‌ی معنایی؛ از خروجی حذف می‌شود. |
| **`Unverified` (تأییدنشده)** | کاندیدی که داوری روی آن انجام نشده (خطای API، پاسخ خالی یا پوشش ناقص)؛ با هشدار صریح نمایش داده می‌شود و نتیجه کش نمی‌شود. |
| **دروازه‌ی موضوع (Subject Gate)** | قاعده‌ی پرامپت: تأیید/تضاد فقط وقتی مجاز است که آیه و گزاره درباره‌ی **فعل/موضوع یکسان** باشند؛ اشتراک احساسی/لفظی کافی نیست. |
| **استدلال‌اول (Reason-First)** | شمای خروجی داور که `reason` را پیش از `label` تولید می‌کند تا مدل پیش از استدلال متعهد به برچسب نشود. |
| **تأیید بیراهه (Off-Target Approval)** | تأیید کاندیدی خارج از فهرست مرتبط طلایی؛ چون فهرست طلایی جامع نیست، این شمارنده **کران بالا** است و برای مقایسه‌ی A/B معتبر است نه به‌عنوان نرخ خطای قطعی. |
| **دیتاست طلایی (Gold)** | ۵۰ گزاره‌ی تأییدشده با آیات مرتبط و برچسب انتظار (`eval/gold_quran.jsonl`). |
| **A/B پرامپت** | آزمایش کنترل‌شده‌ای که بازیابی را یک‌بار انجام می‌دهد و دو پرامپت را روی کاندیدهای یکسان داوری می‌کند (`eval/judge_ab.py`). |
| **کش آگاه از پیکربندی** | کلید کش شامل امضای پیکربندی (استخرها، ترجمه، مدل‌ها) و هش پرامپت داور است؛ تغییر هرکدام نتایج قبلی را ابطال می‌کند. |

## اصطلاحات متون دینی

| اصطلاح | توضیح |
|--------|-------|
| **قرآن کریم** | متن وحیانی اسلام؛ مرجع اصلی. |
| **آیه** | کوچک‌ترین واحد مستقل متن قرآن. |
| **سوره** | فصلی از قرآن شامل مجموعه‌ای از آیات. |
| **شأن نزول** | بافت تاریخی و مناسبت نزول یک آیه؛ کلید تشخیص تعمیم‌پذیری آیه. |
| **نهج‌البلاغه** | مجموعه‌ای از خطبه‌ها، نامه‌ها و حکمت‌های منسوب به امام علی (ع). |
| **خطبه / نامه / حکمت** | سه گونه‌ی متن در نهج‌البلاغه. |
| **الکافی** | یکی از مهم‌ترین مجموعه‌های حدیثی شیعه، شامل اصول، فروع و روضه. |
| **حدیث** | روایت منقول از معصوم. |
| **سند / سلسله‌ی راویان (اسناد)** | زنجیره‌ی راویانی که حدیث را نقل کرده‌اند. |
| **متن (متن حدیث)** | محتوای اصلی کلام معصوم، بدون سلسله‌ی راویان. |
| **معصوم** | در اصطلاح شیعه، شخصیت‌های پاک‌دامن که کلامشان حجت است (پیامبر و ائمه). |
| **اعتبار سندی** | ارزیابی متنی از نظر درستی زنجیره‌ی سند؛ در این پروژه به‌صورت یک **امتیاز الگوریتمی** برای رتبه‌بندی استفاده می‌شود، نه حکم قطعی. |
| **رجال** | دانش بررسی احوال راویان حدیث. |
| **اصول / فروع / روضه** | سه بخش اصلی الکافی. |
| **باب** | فصل یا زیربخش موضوعی در یک کتاب حدیثی. |
